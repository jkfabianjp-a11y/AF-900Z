# AF-900Z

Portafolio académico y profesional enfocado en Ciencia de Datos, Desarrollo de Software e Inteligencia Artificial.

Este proyecto fue desarrollado como una plataforma web para organizar y presentar proyectos, investigaciones, certificaciones y evidencias académicas obtenidas durante la carrera de Ingeniería en Ciencias de Datos.

## Características

* Organización por áreas de especialización.
* Páginas individuales para cada curso.
* Galerías interactivas de imágenes.
* Integración de documentos PDF.
* Incorporación de videos demostrativos.
* Visualización de certificaciones.
* Línea de tiempo académica.
* Diseño moderno, minimalista y responsive.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Git
* GitHub

## Áreas incluidas

* Programación y Desarrollo de Software
* Matemáticas Aplicadas
* Estadística, Probabilidad y Ciencia de Datos
* Bases de Datos
* Ingeniería de Software y Gestión de Proyectos
* Tecnologías Empresariales y Financieras
* Investigación Científica de Proyectos

AF-900Z tiene como propósito documentar de forma profesional el crecimiento académico y técnico adquirido durante la formación universitaria.
